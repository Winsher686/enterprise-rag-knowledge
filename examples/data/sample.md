# 企业知识库使用说明

## 1. 文档上传

用户可以通过前端页面上传 Markdown 或 PDF 文档。

支持的文件类型：

- Markdown（.md）
- 纯文本（.txt）
- PDF（.pdf）

上传后系统会自动解析、切分、向量化并入库。

## 2. 智能问答

上传完成后，用户可以在问答页面输入自然语言问题。

系统会：

1. 将问题向量化
2. 从向量库检索相关 chunk
3. 结合 Prompt 调用大模型生成答案
4. 返回答案并附带引用来源

## 3. 答案溯源

系统会返回答案，并附带引用的原始文档片段。

每条答案都可以追溯到具体的 chunk，便于验证。

## 4. 多轮对话

系统支持多轮对话，能够继承上下文。

用户可以在一次会话中连续提问，系统会记住之前的对话历史。

## 5. 常见问题

### 5.1 支持哪些文件格式？

目前支持 Markdown、TXT、PDF。

### 5.2 答案是否可靠？

系统要求大模型必须基于检索到的内容回答，无引用则拒答。
