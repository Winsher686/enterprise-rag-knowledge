# MVP 范围

## 必须完成

- Markdown / PDF 上传
- 文档解析
- 标题层级 + 递归切分
- 标题注入
- 向量化
- 向量检索
- LLM 生成
- SSE 流式输出
- 答案引用 chunk
- 无引用拒答
- Docker Compose 一键启动

## 可选增强

- 关键词检索
- HyDE
- RRF
- Rerank
- 断崖检测
- MongoDB 多轮会话
- VLM 图片描述
- MinIO 图片存储

## 延后

- NL2SQL
- 多智能体
- GraphRAG
- Neo4j
- 生产级 Milvus 集群
- Qwen3-32B 本地部署
